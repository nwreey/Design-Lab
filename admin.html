Add User

Enter the name, email, and PLAN — the email IS the username, and the usage limits are set automatically from the selected plan (same numbers as the pricing page). The person receives a branded welcome email (Free Plan + their exact limits) with a personal Set Your Password link (valid 7 days); setting it signs them straight in. New users are regular team members by default — grant admin from the Users List if needed.

Signup Requests

Access requests submitted through the public signup page (Early Access Program). Clicking "Approve & email" does the full onboarding in one click: it creates the account automatically (username = their email, trial quotas 1 project / 1 AI auto-fill / 2 design modifications / 3 image edits — adjust in Users List), emails them a personal Set-Password link (valid 7 days), and removes the request from this list — the person then lives under Users List only. If the email fails, the request stays here so you can retry.
